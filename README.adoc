= ISO/TC 12 meetings-data

Structured YAML of ISO/TC 12 (Quantities and Units) plenary and working-group
meetings — agenda, schedule, venues, attendance, deadlines.

This is a **data repository** — no application code, no build step.

== Layout

* `plenary/plenary-meeting-{n}.yaml` — one file per plenary (n = ordinal, 9–23 known)
* `wg/{group-id}-{date}.yaml` — working-group meetings
* `reference-docs/` — source PDFs (agenda, minutes, attendance list). Read-only.

== File shape

Mirror `iso-tc154/www.isotc154.org/_data/events/plenary-meeting-NN.yml`:

[source,yaml]
----
title: "23rd plenary meeting"
ordinal: 23
status: completed
year: 2026
landing_url: /meetings/plenary-meeting-23/

time:
  from: { date: 2026-05-26 }
  to:   { date: 2026-05-26 }

general_area: "Zoom (online)"
country_code: SE   # secretariat country

venues:
  - name: Zoom
    link: https://zoom.us/

host: SIS (Sweden)
secretariat:
  name: ...
  organization: SIS
  email: ...

schedule:
  - date: 2026-05-26
    time: "..."
    event: ...
    description: ...

deadlines:
  - date: ...
    description: ...
----
